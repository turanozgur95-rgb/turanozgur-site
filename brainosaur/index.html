FAQ

Questions parents ask

Does Brainosaur help with the CogAT?

Brainosaur includes all nine CogAT-style question types (picture analogies, sentence completion, picture classification, number analogies, number puzzles, number series, figure matrices, paper folding and figure classification) plus a short-screener practice test. Questions are original, not actual test items.

Does it help with the NNAT3 or NGAT?

Yes. It has the shape-only question types used on nonverbal screeners, a 48-question / 30-minute Shape Test practice run, a six-picture Odd One Out and number-pattern puzzles in the NGAT style.

Which grades is it for?

Kindergarten to 3rd grade (ages 5–9), with a focus on 2nd grade, the most common screening year. Every question is read aloud, so no reading is needed.

How long should my child play each day?

15–20 minutes a day is enough.

Is there a subscription?

No. Brainosaur is a one-time purchase with no subscription, no in-app purchases and no ads.

Does it collect any data?

No. There is no tracking and no data collection, and the game works offline.

Can Brainosaur guarantee my child gets into a gifted program?

No. No practice can guarantee a test result or a placement. Brainosaur helps your child get familiar with the question types, pace and format of school gifted screening tests, and the Test-Ready Report shows which skills need more practice. Brainosaur is independent and not affiliated with any test publisher or school district.

How do I open the Test-Ready Report?

Tap "Report" in the menu. A number appears written in words; type it using digits to pass the parent gate. Inside, tap "Set date" to start the countdown to test day.

Is there a screen time limit?

The game has no built-in timer or daily lock; 15–20 minutes a day is enough. To set a limit, use Screen Time > App Limits on iPhone and iPad, or Google Family Link on Android.

What happens to progress if I delete the app?

There are no accounts or cloud saves, so progress and the Test-Ready Report are stored only on the device. If the app is deleted or its data is cleared, they are erased and we can't restore them, because we never have a copy.
